=== Ofnoa Print Upscaler ===
Version: 1.4.0
Requires PHP: 7.4 (GD required, Imagick optional for PDF input)

מנוע AI לשדרוג גרפיקה ל-4K בלי לשנות אותה, עם הגהה של סוכנים והחזרה כ-PDF במייל.

== שימוש ==
* שורטקוד: [ofnoa_upscaler]  (אפשר title="" subtitle="")
* אלמנטור: הווידג'ט "שדרוג גרפיקה 4K"
* לוח בקרה: שדרוג גרפיקה ← עבודות / הגדרות

== הצינור ==
1. קבלת קובץ (PNG/JPG/WEBP, ו-PDF אם יש Imagick) לתיקייה פרטית חסומה.
2. הגדלה: Real-ESRGAN (×2/×4, עד שני מעברים, face_enhance כבוי) דרך שרשרת מנועים
   לפי עדיפות: free.ai (חינם, מכסה יומית) → deAPI ($5 קרדיט) → המחשב המקומי (חינם)
   → Replicate (בתשלום). מנוע שנכשל / לא ענה בזמן – עוברים לבא. כולם נכשלו – Lanczos.
   קובץ שכבר 4K – לא מוגדל. קובץ גדול מדי למודל – Lanczos קלאסי.
3. בדיקת נאמנות דטרמיניסטית: הקטנה חזרה לגודל המקור והשוואת פיקסלים
   (ממוצע + אזור גרוע ברשת 24×24).
4. סוכני הגהה (Claude): תמלול מקור, תמלול תוצאה (עיוור), מפקח השוואה ויזואלית
   (תצוגה מלאה + 4 רבעים מוגדלים), מגיה איות/דקדוק/פרטי קשר, והגה ראשי.
   ההחלטה הסופית = המחמירה מבין ההגה הראשי והבדיקות הדטרמיניסטיות.
5. PDF ב-300DPI: ללא איבוד איכות (זרם ה-PNG כמו שהוא) או JPEG 97 כשהקובץ גדול.
6. מייל HTML עם הדוח המלא + PDF מצורף (או קישור הורדה חתום ל-30 יום).

הגרפיקה לעולם לא "מתוקנת" – שגיאות כתיב מדווחות בלבד.

== מפתחות ==
עדיף ב-wp-config.php:
define( 'OFP_FREEAI_KEY', 'sk-free-...' );
define( 'OFP_DEAPI_KEY', '...' );
define( 'OFP_REPLICATE_TOKEN', '...' );
define( 'OFP_ANTHROPIC_KEY', '...' );

== המחשב המקומי ==
הגדרות ← "הורדת סקריפט ה-worker לווינדוס" ← קליק ימני ← Run with PowerShell.
הסקריפט מוריד את realesrgan-ncnn-vulkan, מושך עבודות מ-/wp-json/ofp/v1/worker
ומחזיר את התוצאה. אימות בכותרת X-OFP-Worker-Key.

== 1.2.0 ==
* דאשבורד "שדרוג מהיר" למנהל (שדרוג גרפיקה ← שדרוג מהיר): העלאה, התקדמות חיה, לפני/אחרי,
  הורדת PNG ו-PDF באותו דף, ורשימת הקבצים שנוצרו. הדף מקדם את העבודה בעצמו – לא תלוי ב-WP-Cron.
* שלב חדש לפני ההגדלה: שיפור תמונה לפי פרומפט (deAPI Image Edit, ברירת מחדל QwenImageEdit_Plus_NF4).
  חל על כל סוג קובץ. הפרומפט וההנחיות השליליות ניתנים לעריכה בהגדרות; אפשר לכבות.
  אם השיפור נכשל / אין מפתח deAPI – ממשיכים להגדלה רגילה של המקור.
* בתמונה משופרת בדיקת הפיקסלים היא למידע בלבד; ההחלטה לפי הסוכנים (זהות, רקע, טקסט, לוגואים).
* אפשרויות לכל עבודה בדאשבורד: שיפור / הגהה / שליחת מייל.
* תיקון: הוסר הפרמטר temperature מהקריאות ל-Claude (לא נתמך במודלים החדשים).
